Ekran A — wybór usług Klient wybiera: usługę główną (wymiana kół lub przełożenie) + dodatki (wyważanie, wentyl). Parametry: liczba kół (2/4) + typ felgi (stal/alu) — wpływają na czas. Formuła: (durationPerWheel + alloyMod) × wheelCount per usługa, suma = totalDuration. Wyświetlane live: "88 min · 260 zł" zanim klient przejdzie do terminu.
Ekran B — wybór terminu Sloty = godziny startu. Każdy chip: start · do end (= start + 88 min). Widoczność terminu: start + 88 min ≤ closeTime danego bloku obsady. Kolor: Wolny (zielony) / Ostatni (żółty, zajmuje ostatnie wolne stanowisko) / Zajęty. Granularność: co 30 min lub co 60 min (konfigurowalne globalnie przez providera — nowy param).
Silnik slotów (uproszczony opis) Wejście: providerId + date + serviceIds + wheelCount + rimType. Oblicz: totalDuration = ∑ serviceDurationPerWheel(rimType) × wheelCount. Dla każdego możliwego startu t (co granularity): sprawdź czy w WorkingHours w przedziale [t, t+totalDuration] jest dostępne stanowisko (uwzględniając istniejące rezerwacje i podział dnia / capacity blocks).
