SSR, SEO & share

  • SSR — strona generowana przy publish/edit providera (ISR), cache 5 min; fallback do on-demand rendering gdy nowy warsztat.
  • OG tags (pokazane jako preview) — og:title, og:description, og:image (1200×630, dynamic z nazwą + 4,8★), twitter:card=summary_large_image.
  • JSON-LD — LocalBusiness + AggregateRating + Review schema (pokazane itemscope na opinii Marka) → rich snippets w Google.
  • Canonical URL — opony.app/p/<slug>; redirect z app.opony.app/p/<slug> aby share-URL nie rozsynchronizował SEO.
  • Native share (US-42) — Web Share API z fallbackiem na copy-link; PostHog event share_provider z atrybucją (Messenger / WhatsApp / Email / native).
  • Breadcrumb — Opony › Nowy Sącz › Wulkanizacja; każdy poziom to osobny kanoniczny URL (/nowy-sacz listuje warsztaty w mieście dla SEO long-tail).

Stany & deep-link do aplikacji

  • Zero booking w przeglądarce — landing nie ma kalendarza, slot-pickera ani formularza rezerwacji. Cały flow odbywa się w app.opony.app (Expo RNW) — landing tylko „wystawia" profil dla SEO i share.
  • CTA „Otwórz w aplikacji" w topbarze i sidebarze — Universal Link opony://p/<slug>; fallback na web-app (app.opony.app/p/<slug>) gdy natywka nie zainstalowana.
  • QR code — dla desktop-userów (głównie share z laptopa); redirect przez link.opony.app z trackingiem atrybucji (utm_source=landing_qr).
  • Mini-phone preview — decorative, pokazuje jak wygląda profil w aplikacji (hero + rating + CTA „Wybierz termin") — uczy usera czego się spodziewać po kliknięciu.
  • App Store / Google Play badges — v0 Expo ma web-app (app.opony.app) + EAS build do natywki (TASK-007b); w v0 linki pokazują web-app fallback jeśli store-build niegotowy.
  • Sticky sidebar — position: sticky; top: 76px; CTA widoczne przez cały scroll — primary action nigdy nie znika.
  • Gallery +5 zdjęć — lightbox (esc, strzałki, swipe); preload thumbnails, lazy main image.
  • Reviews — 3 top + „Zobacz wszystkie (127)" → /p/<slug>/opinie (sub-path dla SEO long-tail „opinie wulkanizacji nowy sącz").
  • PENDING_APPROVAL — strona zwraca 404 (nie indexed); po approvalu od razu live.
  • A11y — h1 tylko raz (nazwa warsztatu); reviews mają itemscope Schema.org dla rich snippets.
